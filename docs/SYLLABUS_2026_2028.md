# Cambridge O Level Computer Science 2210 syllabus mapping

The database stores the 2026–2028 syllabus as a versioned hierarchy:

- `topics`: the 10 top-level syllabus topics
- `syllabus_versions`: the applicable exam-year range and official source
- `syllabus_subtopics`: the 24 numbered content sections
- `syllabus_objectives`: concise, individually taggable learning objectives
- `questions.syllabus_objective_id`: the objective assessed by a question

The current import is `2026-2028-v5`, based on the Cambridge 2210 syllabus for examinations in 2026, 2027 and 2028. Objective wording is intentionally concise; use the official syllabus for authoritative wording and detailed notes and guidance.

Official source: https://www.cambridgeinternational.org/Images/697287-2026-2028-syllabus.pdf

## Authoring rule

Every new question should have both `topic_id` and `syllabus_objective_id`. The selected objective must belong to the selected topic. Assets such as diagrams and images remain attached through `question_assets`; tables can be represented directly in `questions.stem_blocks`.
